### 1. Evaluation-Date Reminder (Backend)

**Problem:** Wenn ein Consent-Beschluss ein `evaluationDate` hatte und dieses Datum erreicht war, passierte: nichts. Der Kreis wurde nie erinnert.

**Lösung:**
- `round.services.ts`: neue Methode `getRoundsDueForEvaluation()` + `checkEvaluationDates()`
  - Findet completed Rounds wo `evaluationDate <= now` und `evaluationReminderSent !== true`
  - Sendet Teams notification via `notifyEvaluationDue()`
  - Audit-Log Eintrag
  - Setzt `evaluationReminderSent = true`
- `round.controllers.ts`: neue Action `checkEvaluationDates()` 
- `round-custom.ts`: neue Route `POST /rounds/check-evaluations`
- `teamsWebhook.ts`: neue Methode `notifyEvaluationDue()` (orange/gelb Theme)
- `strapi.ts`: `checkEvaluationDates()` auf Client-Seite hinzugefügt

**Aufruf:** Can be triggered periodically (cron / admin action) — consent-Beschlüsse werden "lebendig" nicht eingefroren.

### 2. Info-Request Reply UI (Frontend + Backend)

**Problem:** Owner bekam Teams-Notification wenn jemand B/C Enthaltung wählte — aber hatte in der UI keine Möglichkeit zu antworten. Requester wurde nie erneut eingeladen.

**Backend:**
- `abstention.controllers.ts`: neue Action `answerInfoRequest()`
  - Owner schreibt Antwort auf B/C Abstention
  - Speichert `ownerAnswer`, `answeredAt`, `answered: true` auf Abstention
  - Teams Notification an Requester via `notifyInfoRequestAnswered()`
  - Audit-Log
  - Nur der Projekt-Owner darf antworten (Guard Check)
- `abstention-info-request.ts`: neue Route `POST /abstentions/:id/answer`
- `teamsWebhook.ts`: neue Methode `notifyInfoRequestAnswered()`

**Frontend:**
- Neues Component: `InfoRequestReplyPanel` (`components/InfoRequestReply/InfoRequestReplyPanel.tsx`)
  - Lädt alle B/C Abstentions für eine Round
  - Owner sieht inline Answer-Form pro Anfrage (mit textarea + Submit)
  - Non-Owner sieht nur "X Anfragen offen"
  - Beantwortet: grüner Bereich mit Antwort sichtbar
  - Eingebunden in `projects/[id]/page.tsx` neben AbstentionAnalysis
- `strapi.ts`: `answerInfoRequest()` hinzugefügt
